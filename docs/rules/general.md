# Rules: general

Generated by `slipway digest` from the `## Rules` sections of the accepted records, for the whole repository. Do not edit by hand: change the record and run `slipway digest` again.

- **Commands.** Run the repository's commands as `slipway run <name>` with the names in `slipway.config.json`, never by their tool's own name; a cached result is a proof, and nothing bypasses the cache. ([0002](../adr/0002-the-process.md), with [0001](../adr/0001-the-process.md))
- **Records.** Amend a record in place only while a plan naming it in `- Records:` is `in progress`; otherwise supersede it, and carry the parent's surviving rule lines into the successor's `## Rules`. ([0002](../adr/0002-the-process.md), with [0001](../adr/0001-the-process.md))
- **Digests.** Never edit a digest by hand: change the record's `## Rules` and run `slipway digest`. ([0002](../adr/0002-the-process.md), with [0001](../adr/0001-the-process.md))
- **Decisions.** A decision is the operator's when overturning it later would take a migration, a change a client already consumes, a weaker security behaviour or a new runtime dependency. Scope asks them in one batch; a step takes one the plan did not settle provisionally, writes its line in the decisions file, and goes on. ([0002](../adr/0002-the-process.md), with [0001](../adr/0001-the-process.md))
- **Review.** A step is reviewed once, in a fresh context, by a reviewer that did not build it; confirmed findings go back to the builder, and there is no second round. ([0002](../adr/0002-the-process.md), with [0001](../adr/0001-the-process.md))
- **Commits.** A step is one commit on the lane branch whose body has `Built:`, `Step check:`, `Review:`, `Flakes:` and `Time:`, plus at most one `fix(<scope>): D<n>.<k> review findings` commit for its review's confirmed findings; never force-push a lane branch, and never commit to the default branch from a step. ([0002](../adr/0002-the-process.md), with [0001](../adr/0001-the-process.md))
- **Branch-first.** Plan and scope commit on a lane branch, never on the default branch; only the ship's merge reaches it. ([0002](../adr/0002-the-process.md))
- **Ship.** A lane closes with `/slipway:ship`, never with Claude Code's own `/ship`; nothing merges to the default branch before it. Its one proof is `slipway run gate` on the ship commit, with CI where the lane's `CI:` asks. ([0002](../adr/0002-the-process.md), with [0001](../adr/0001-the-process.md))
