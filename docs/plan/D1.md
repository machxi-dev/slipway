- Status: in progress
- Records: none

Three follow-ups left from v0.1 and v0.2. First, the README's status line says what works today instead of "the v0.1 skeleton". The docs site's Getting started page copies that line, so it changes too. Second, the development loop in the README and the design loads the plugin from a separate worktree of `main`, not from the repository being edited. Claude Code 2.1.332 treats every file under a `--plugin-dir` path as sensitive and refuses edits to it. Third, the lock tests confirm their dead-holder pid is gone before they use it, so they stop flaking on Windows. This is the first lane run with the plugin on itself, and its ship tags `v0.2.0` (design §9).
