# The Slipway docs site

The site at https://machxi-dev.github.io/slipway/, built with [VitePress](https://vitepress.dev) and deployed to GitHub Pages by `.github/workflows/docs.yml` on every push to `main` that touches what it is built from.

Its dependencies live in this folder alone. The plugin stays dependency-free: nothing here is read by `node --test` or `claude plugin validate`.

```sh
cd site
npm ci
npm run dev       # http://localhost:5173/slipway/
npm run build     # writes .vitepress/dist; fails on a dead link
```

## Where the pages come from

Most pages are generated by `scripts/sync.mjs`, which `dev` and `build` run first, from the repository's own files. They are gitignored; to change one, edit its source and rebuild.

| Page | Source |
| --- | --- |
| Home | `README.md` (the intro, the feature bullets, the commands table, install) and `.claude-plugin/plugin.json` (the tagline, the version) |
| Getting started, Contributing | `README.md` |
| The method | `templates/process-record.md`, with the default folders of `templates/slipway.config.json` |
| Commands | `README.md`'s table and each `skills/<name>/SKILL.md` |
| Design, Measurements, Changelog | `docs/design.md`, `docs/measurements.md`, `CHANGELOG.md` |

The script rewrites relative links to the site's pages or to the file on GitHub, and every `§4.5` to a link into the design. A `§` naming no section of the design, a missing README section or a config key `src/guide/configuration.md` does not name fails the build, so the site cannot drift quietly.

`src/guide/configuration.md`, the logo and the theme are the only hand-written content.
